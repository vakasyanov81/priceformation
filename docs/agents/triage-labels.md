# Triage labels

| Роль | Метка в GitHub | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Требует оценки сопровождающего |
| needs-info | needs-info | Ожидает уточнений от автора |
| ready-for-agent | ready-for-agent | Готова к автономной реализации агентом |
| ready-for-human | ready-for-human | Требует реализации человеком |
| wontfix | wontfix | Выполняться не будет |

Когда навык упоминает роль, использовать соответствующую метку.
