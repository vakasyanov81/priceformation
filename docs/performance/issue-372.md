сразу из приведённых полей. Раньше создавались семь пустых VO, после чего
заполненные группы пересоздавались через `dataclasses.replace` с обходом
всех полей группы. Приведение, накопление ошибок, extra и порядок ключей

## Воспроизведение

Из корня, отдельно на базовой и изменённой версии, с теми же локальными
данными. Команда создаёт отдельную временную папку, пять новых процессов и
JSON со всеми листами первого результата для сравнения между версиями.
Папка содержит пользовательские данные; не публиковать её содержимое.
Таймер в `_make_price_once.py` охватывает полное формирование и запись,
но не настройку сервисов перед ним.

```bash
PYTHONPATH=src uv run python - <<'PY'
import json
import os
import subprocess
import sys
import tempfile
from pathlib import Path
from statistics import median
from openpyxl import load_workbook

root = Path.cwd()
folder = Path(tempfile.mkdtemp(prefix='pf372-'))
times = []
for index in range(5):
    result = folder / str(index)
    result.mkdir()
    with (result / 'console.txt').open('w') as console:
        subprocess.run(
            [sys.executable, str(root / 'load_tests/_make_price_once.py'),
             str(result), str(result / 'elapsed')],
            env=dict(os.environ, PYTHONPATH=str(root / 'src')),
            stdout=console, stderr=subprocess.STDOUT, check=True,
        )
    times.append(float((result / 'elapsed').read_text()))
    if index == 0:
        tables = {}
        for path in sorted(result.glob('*.xlsx')):
            book = load_workbook(path, read_only=True, data_only=False)
            tables[path.name] = {sheet.title: list(sheet.values) for sheet in book}
            book.close()
        (folder / 'tables.json').write_text(
            json.dumps(tables, default=str, ensure_ascii=False), encoding='utf-8')
print(folder)
print(times, 'median:', median(times), 'min/max:', min(times), max(times))
PY
```

Сравнить `tables.json` двух запусков побайтово; если дата запуска отличается,
сначала отдельно проверить штатные поля даты и имена файлов.

Регрессии — `tests/test_domain/test_row_item/test_initialization.py`:
сопоставление конструктора с последовательной публичной записью всех полей
реестра, дефолтов, ошибочных чисел, нормализации склада, extra, None/False/0
и порядка ключей; отдельный тест запрещает промежуточный replace и падает
на исходном конструкторе. Существующие тесты фильтров складов сохраняются.
