# Определение типа товара по названию номенклатуры и параметрам

Инструкция описывает, как по строке прайса (название + параметры) определить **тип товара**
(поле `type_production`) по общепринятым в шинной отрасли принципам.

Составлено по фактическим прайсам поставщиков: `autosnab54_ru`, `four_tochki`, `mim`,
`pioner`, `poshk`, `stk`, `zapaska`. Правила намеренно **не** повторяют текущую логику
`tire_size_category` / `header_rows`, а формулируют независимый отраслевой подход, на который
её затем можно выверить.

---

## 1. Канонические типы товара

Целевой набор значений поля `type_production` (совпадает с отраслевым делением):

| Тип | Что входит | Отраслевые синонимы в прайсах |
|---|---|---|
| `Легковая шина` | Шины для легковых авто, кроссоверов и SUV | Легковая, SUV, Грязевая (M/T), UHP |
| `Легкогрузовая шина` | Коммерческие шины для лёгкого коммерческого транспорта (LCV), микроавтобусов, «каблучков» | Легкогрузовая, C, LT, CP, Van, «коммерческая» |
| `Грузовая шина` | Шины для грузовиков, автобусов, прицепов (TBR, LTR) | Грузовая, груз., автошина/автопокрышка (в прайсах грузовых листов) |
| `Спецшина` | Сельхоз-, индустриальные, карьерные, складские (OTR): тракторы, погрузчики, экскаваторы | Спецшина, Спецтехника, спецпокрышка, сельхозшина, индустриальная |
| `Мотошина` | Мотоциклы, скутеры, квадроциклы, мотокарты | Мото, Мотошина |
| `Автокамера` | Камеры (в т.ч. легкогрузовые, грузовые, спец) | Автокамера, Камера |
| `Ободная лента` | Ободные ленты / флипперы | Ободная лента, Об/лента, Об/л, Флиппер |
| `Уплотнительное кольцо` | Уплотнительные кольца для колёс/камер | Уплотнительное кольцо |
| `Диск` | Колёсные диски (стальные и литые), в сборе | Диск, Автодиск, Колесо |

Подтипы, которые **не** являются отдельным типом (это уточняющие признаки, а не `type_production`):

- Сезон: `Летняя`, `Зимняя`, `Всесезонная` (сезон шины).
- Шипы: наличие шипов («шип», «шипы», «Ш.»).
- Диски: `Литой` / `Штампованный` (способ изготовления); `Легковой` / `Грузовой` (назначение).
- Грузовые/спец: ось (`рулевая`, `ведущая`, `прицепная`, `универсальная`), `PR`, `TL`/`TT`/`TTF`.
- `Грязевая`, `SUV`, `A/T`, `M/T`, `H/T` — назначение легковой шины; отдельным типом не становится.

## 2. Порядок определения (первое совпадение выигрывает)

```
0. Нормализовать строку (регистр, разделители, гомоглифы).
1. Нешинные товары — по ключевому слову:
   кольцо → камера → лента → диск.
2. Если найден шинный размер — это шина, определить подтип:
   а) тип размера: метрический / дюймовый / сельхоз / индустриальный / мото;
   б) спецшина  — маркеры спецтехники или размер (в)/(г);
   в) мотошина  — маркеры мото или размер (д);
   г) грузовая / легкогрузовая / легковая — по суффиксу, диаметру, PR и индексу нагрузки.
3. Тип определяется **независимо** по названию и параметрам. Колонка категории поставщика —
   лишь слабый ориентир для сверки, но **не источник истины**: она может быть неверной (см. §7).
```

Ключевое правило отрасли: **начинать с размера**. Размер — самый устойчивый признак: он
почти всегда присутствует и однозначно отделяет легковые от грузовых и спец.

> **Категория поставщика может быть некорректной.** Поставщики путают легковые и
> легкогрузовые, кладут `R17.5` в легковые, `SUV` — в спецшины, «спецтехнику» — в грузовые
> и наоборот. Поэтому тип **всегда вычисляется заново** по правилам этой инструкции, а
> колонка поставщика используется только для перекрёстной проверки и логирования расхождений.
> Если вычисленный тип расходится с категорией поставщика — доверяем вычисленному, а
> расхождение фиксируем в логе.

## 3. Нешинные позиции

Проверяются **до** анализа шин: у камер, лент и дисков тоже бывают размеры, похожие на шинные.

### 3.1. Автокамера

Признак: слово `камер` (`Автокамера`, `Камера`, `кам.`).
Примеры: `Автокамера 11.2-20`, `Автокамера 12.5/80-18`, `Камера СВК 11.00-20 ГК-145`,
`(Не использовать) Камера СВК 18.4-26 ТК`.

Размер камеры бывает в «шинном» виде (`11.2-20`, `425/85R21`, `1220x400-533`) — после
слова `камера` тип уже определён, размер на тип не влияет.

### 3.2. Ободная лента (флиппер)

Признак: слово `лент` в составе `ободная лента`, `об/лента`, `об/л`.
Примеры: `Ободная лента 16/70-20 (300-508)`, `130-10 об/лента`, `205-457 (12.00-18) об/лента`,
`300-508 (14.00-20) об/лента`.

### 3.3. Уплотнительное кольцо

Признак: `уплотнительн` + `кольц`, либо `кольцо` рядом с размером/диаметром (`R25 d=6.6мм`).
Примеры: `Уплотнительное кольцо R25 d=6.6мм`, `Уплотнительное кольцо R25 d=9.8мм`.

### 3.4. Диск

Признак: слово `диск` (`автодиск`, `Диск стальной`, `Колесо`), **или** маркер посадочного
места (размер диска `ширина×диаметр` + разболтовка `NxM/N*M` + вылет `ET` + ступица `DIA`).

Примеры:
- `5,5x16/6x170 ET106 D130 Газель Silver`
- `7,5x22,5/10x335 ET165 D281 M22 Sil`
- `17 TREBL 7.0*17 5*112 ЕТ43 57.1 Black`
- `Диск стальной YONGZHENG 22,5*11,75 10 26мм ЕТ0 D281`

Уточнение внутри типа (не отдельный тип):
- `Литой` (alloy) vs `Штампованный` (steel) — способ изготовления;
- `Легковой` vs `Грузовой` — назначение (грузовой: число отверстий ≥ 6, PCD ≥ 200,
  диаметр ≥ 17.5, крупная `D` 164–281).

## 4. Типы размеров шин

Сначала распознаётся **форма** размера; именно она задаёт основную ветку.

### (а) Метрический размер (легковые / коммерческие / грузовые)

Форма: `ширина / профиль R диаметр`, разделители `R`, `-`, `/`, вариант `ширина/профиль/диаметр`.
Примеры: `205/55R16`, `195/75R16C`, `225/75R16C`, `285/75R16LT`, `315/80R22.5`, `215/75R17.5`,
`265/70/19.5` (вариант mim).

Признаки подтипа:
- суффикс **C / LT / CP** → коммерческая (легкогрузовая);
- диаметр **17.5 / 19.5 / 22.5** → грузовая (TBR);
- **двойной индекс нагрузки** (`107/105`, `152/149`) при диаметре ≥ 16 → легкогрузовая/грузовая;
- широкий диаметр (≥ 20) и высокий профиль (`295/80`, `315/80`) → грузовая.

### (б) Дюймовый / десятичный размер (грузовые, LTR)

Форма: `NN.NN R NN` или `NN R NN.N`.
Примеры: `10.00R20`, `12.00R24`, `11R22.5`, `13R22.5`, `7.50R16`, `8.25R16`, `8.25R20`,
`9.5R17.5`, `215/75R17.5`, `11.00-20` (диагональная).

Признак грузовой: посадочный диаметр ≥ 17.5, либо PR ≥ 14 (`PR18`, `18PR`, `16`),
либо размер `≥ 10.00`.

### (в) Сельхозразмер

Форма: число с `-` или `.` и малым/дробным профилем, часто `L`.
Примеры: `11.2-20`, `12.4L-16`, `16.9-24`, `18.4-26`, `18.4-24`, `15.5-38`, `14.9R30`,
`15.50R38`, `23.1-26`, `28.1R26`, `30.5R32`, `360/70R24`, `420/70R24`, `16.5/70-18`, `12.5/80-18`.
Дополнительно: индекс скорости **A1–A8** (`111A6`, `123 A6`, `129 A8`, `158 A8`).

### (г) Индустриальный / карьерный размер (OTR)

Форма: первое число ≤ 10 (или размер вида `N*M-N`), либо «гиганты» с `-`.
Примеры: `5.00-8`, `6.00-9`, `6.50-10`, `7.00-12`, `7.00-15`, `8.25-15`, `9.00-20`,
`10-16.5`, `12-16.5`, `16*6-8`, `18*7-8`, `21*8-9`, `23*9-10`, `16/70-16`, `16/70-20`,
`20.5/70-16`, `17.5-25`, `20.5-25`, `23.5-25`, `26.5-25`, `29.5-25`, `17.5L-24`, `23.5R25`, `26.5R25`.
Дополнительно: коды TRA `E3/L3`, `G2/L2`, `R-4`, `L5`, `R1`, `E4/L4`; слова `карьер`,
`индустр`, `волна`, `шашка`, `ёлка`, `ромбик`, `цельнолитая`/`SOLID`, `экскаватор`, `погрузчик`.

### (д) Моторазмер

Форма: дюймовый (`3.50-10`) или метрический с малым диаметром (`120/70-12`, `130/80-17`),
малый индекс нагрузки, отсутствие `C`/`PR`; категория поставщика `Мото`.

### (е) Флотационный (дюймовый внедорожный) размер

Форма: `наружный_диаметр × ширина R/- посадочный` — `31x10.5R15`, `33X12.50R20`,
`35x12.5R17`, `37X12.50-16LT`. Тот же вид `N×M–K`, что и промышленный (г), но
посадочный диаметр ≥ 15.
Назначение: `Легковая шина` — внедорожники и пикапы (`A/T`, `M/T`); суффикс `C`/`LT`/`CP`
переводит в `Легкогрузовая`. Посадочный < 15 (`16*6-8`, `18*7-8`, `24x10-11`) —
индустриальная/квадро `Спецшина`.

## 5. Правила по типам шин

### 5.1. Спецшина

Срабатывает, если **любое** из:

1. Есть маркер спецтехники: `сельхоз`, `спец`, `индустр`, `карьер`, `клюшк`, `волна`, `шашка`,
   `ёлк`/`елк`, `ромбик`, `экскаватор`, `погрузчик`, `цельнолит`/`SOLID`, `трактор`.
2. Есть код TRA: `E3/L3`, `G2/L2`, `R-4`, `L5`, `R1`, `E4/L4`, `G2/L2`.
3. Размер относится к сельхоз- (в) или индустриально-карьерному (г) типам.
4. Есть агро-индекс скорости `A1–A8`, нет признаков грузовой оси/PR.
5. Слово `спецшина`/`спецпокрышка` в конце названия (poshk, pioner).

Примеры: `11.2-20 Ф-35 н.с.8 инд.114 НКШЗ сельхозшина`, `16.9-28 Rockbuster H658 R-4`,
`17.5-25 RockBuster H108A E3/L3 н.с.28 спецшина`, `10-16.5 RockBuster SKS-1 12PR TL (клюшка)`,
`18*7-8 (180/70-8) Haulking S-301 цельнолит. спецшина`.

Внутренние подтипы спецшин (для статистики/аналитики, не для `type_production`):
сельхоз (`A-индекс`, `R-1`/`R-4`, размеры 11.2-20…28.1R26), индустриальные/складские
(`5.00-8`…`12-16.5`, `SOLID`), карьерные (`17.5-25`…`29.5-25`, `L5`, `E3/L3`).

### 5.2. Мотошина

Срабатывает, если категория поставщика `Мото`/`Мотошина`, **или** размер типа (д), **или**
явный мото-признак. Проверяется **после** спецшины (квадро-размеры пересекаются).

### 5.3. Грузовая шина

Срабатывает, если не спец/мото и есть **любое** из:

- посадочный диаметр **17.5 / 19.5 / 22.5 / 24** (десятичный, «грузовой»);
- дюймовый/десятичный размер (б) с диаметром ≥ 17.5 (`10.00R20`, `11R22.5`, `12.00R24`);
- метрический размер (а), диаметр ≥ 20 и профиль ≥ 65 (`295/80R22.5`, `315/80R22.5`);
- PR ≥ 14 (`14PR`, `16PR`, `18PR`, `20PR`, `22PR`, `24PR`) у дюймового размера;
- двойной индекс нагрузки ≥ 130 (`152/149`, `143/141`, `126/124`) при грузовом диаметре;
- маркер оси `рул`/`вед`/`прицеп`/`трал`/`унив` в грузовом контексте;
- слова `карьер`, `стройка`, `региональная`, `шашка`, `змейка` (грузовые протекторы).

Примеры: `315/80R22.5 Blackhawk BDR75 ... 152/149M 18PR`, `10.00 R20 И-281 ... 146/143J НКШЗ`,
`7.50 R16 HIFLY HH-306 ... 118/114M унив.ось`, `12.00R24 DRC D931 20PR ... карьер`.

Пограничные дюймовые 16″ (`7.50R16`, `8.25R16`): если поставщик размещает их в грузовом
листе — это **грузовая**; если есть суффикс `LT` (`7.50R16LT`) — это **легкогрузовая**.

### 5.4. Легкогрузовая шина

Срабатывает, если не грузовая и есть **любое** из:

- суффикс размера **C / LT / CP** (`195/75R16C`, `185/75R16C`, `285/75R16LT`, `165R13C`);
- метрический размер с **двойным индексом нагрузки** и диаметром 13–17 (`195/75 R16C 104/102`,
  `225/75 R16C 121/120`);
- PR 8–12 у метрического/дюймового размера (`8PR`, `10PR`, `12PR`) при диаметре ≤ 17.5;
- структурный маркер поставщика **`C`/`LT`/`CP`** в поле «Тип авто»/`tire_type` (mim):
  колонка учитывается, даже если суффикса нет в собранном названии;
- «фургонные»/коммерческие модели: `Van`, `Vettore`, `EffiVan`, `TRACVAN`, `BLU-TRAC VAN`,
  `Connex Van`, `RxQuest Van`, `Cargo`, `LCV`.

Примеры: `195/75 R16C VIATTI Vettore Brina (V-525) 107/105R`, `225/75R16C Triangle TV701 121/120S`,
`165 R13C Rapid EffiVan 94/93R`, `225/75 R16 C` (`Тип авто = C`), `7.00R16LT Triangle TR558`.

### 5.5. Легковая шина

Всё остальное, что имеет шинный размер и не попало выше:

- метрический размер с одноместным индексом нагрузки, диаметр 12–22: `205/55R16`,
  `235/55R17`, `255/55R19`, `265/70R16`;
- целевая аудитория: легковой автомобиль, кроссовер/SUV (`SUV`, `CUV`);
- назначение `Грязевая`/`M/T`/`A/T`/`H/T`/`Sport`/`Comfort`/`UHP` — это всё ещё легковая шина.

Примеры: `205/55 R16 Rapid P309 91V`, `235/55R17 Nordman 8 SUV 103T`,
`215/65 R16 Кама НК-242 102T`, `265/50R20 ... 111V`.

## 6. Формальные признаки (регулярики-ориентиры)

```text
# размеры
METRIC   = \b(\d{3})\s*/\s*(\d{2,3})\s*[Rr]?\s*[-/]?\s*(\d{2}(?:[.,]5)?)\s*([CcСс]|[Ll][Tt])?\b
METRIC2  = \b(\d{3})\s*/\s*(\d{2})\s*/\s*(\d{2}(?:[.,]5)?)\b                  # 265/70/19.5
INCH     = \b(\d{1,2}(?:[.,]\d{1,2})?)\s*[Rr]\s*(\d{2}(?:[.,]5)?)\b             # 10.00R20, 11R22.5
DASH     = \b(\d{1,2}(?:[.,]\d{1,2})?)\s*-\s*(\d{1,2}(?:[.,]\d)?)\b            # 6.50-10, 17.5-25
MULT     = \b(\d{2,3})\s*[*xх×]\s*(\d{1,2}(?:[.,]\d{1,2})?)\s*(?:-|R)\s*(\d{1,2})\b   # 18*7-8, 31x10.5R15
AGRO_AI  = \b\d{2,3}\s*[Aa][1-8]\b                                             # 114A6, 129 A8
PR       = \b(?:PR)?\s?(?:8|10|12|14|16|18|20|22|24)\s?PR?\b
LT_SUFFIX= (?:\b[CcСс]\b|\b[Ll][Tt]\b|\bCP\b)\s*(?:\d|$|[^\w])                    # 16C, R16LT
AXLE     = (рул|вед|прицеп|трал|унив)
SPEC     = (сельхоз|спец|индустр|карьер|клюшк|волна|шашка|ёлк|ромбик|экскаватор|погрузчик|цельнолит|SOLID)
TRA      = \b[ELGR]\d?/?[ELGR]?\d?\b\s*|(?:E3/L3|G2/L2|R-4|L5|R1|E4/L4)
DISK     = \d+(?:[.,]\d+)?\s*[*xх×]\s*\d+(?:[.,]\d+)?\s*(?:/|J|JJ|ET|$)            # 7,5x22,5 / 7.0*17
NONTIRE  = (уплотнительн.*кольц|кольц.*R\d|камер|лент|диск|об/л)
```

> Это ориентиры для реализации, а не готовый парсер: сначала нормализуют гомоглифы
> (`С/C`, `Р/P`, `Х/X`, `М/M`, `Е/E`, `О/O`, `А/A`, `В/B`, `Т/T`, `Н/H`, `К/K`), затем
> `\xa0` и `,` в размерах приводят к каноничному виду.

## 7. Категория поставщика: может быть неверной

Категория/тип из прайса поставщика — **неприоритетный сигнал**, а не готовый ответ.
К распространённым ошибкам поставщиков относятся:

- `SUV`, `Грязевая`, `A/T`, `M/T` указаны как отдельный тип вместо подтипа легковой шины;
- путаница `Легковая` ↔ `Легкогрузовая` (маркировка `C`/`LT` игнорируется);
- `R17.5`/`R19.5` (грузовые) помечены как легковые или спецшины;
- шины для лёгких грузовиков (`VAN`, `Vettore`, `EffiVan`) помечены как `Грузовая`;
- спецшины (сельхоз, индустриальные) помечены как легковые/грузовые, и наоборот;
- пустой/шаблонный тип у неоднородных листов.

### Правило

1. Тип определяется **независимо** по названию и параметрам (алгоритм §2–§5).
2. Категория поставщика берётся в расчёт **только после** независимого вычисления и служит
   сигналом для перекрёстной проверки, а не для подмены результата.
3. При расхождении вычисленного типа с категорией поставщика — приоритет у вычисленного,
   расхождение пишется в лог (симптом неверной категории у поставщика).

Секционные прайсы (тип задан не строкой, а листом/файлом) — тип определять **по содержимому
строки**, а название листа использовать лишь как подсказку; лист может быть неоднородным:

- `four_tochki`: лист «Шины» — тип по размеру/маркерам строки (в т.ч. `Тип шины`), лист
  «Диски» → `Диск`;

## 8. Приоритет при коллизиях

Порядок разрешения спорных случаев (сверху — сильнее):

1. Явное слово типа в названии (`камера`, `лента`, `кольцо`, `диск`, `сельхозшина`,
   `спецшина`, `спецпокрышка`, `автошина`) — обычно сильнее размера.
2. Маркеры спецтехники и код TRA — сильнее «грузовой» ветки.
3. Суффикс `C`/`LT`/`CP` — сильнее грузовой ветки (делает шину легкогрузовой).
4. Грузовой диаметр/PR/двойной индекс/ось — сильнее легковой.
5. Категория поставщика **не** участвует в разрешении коллизии: она может быть неверной.
   Она применяется только для перекрёстной проверки уже вычисленного типа (см. §7).

Типичные коллизии:

- `7.50R16` vs `7.50R16LT` — без суффикса чаще грузовая, с `LT` — легкогрузовая.
- `215/75R17.5` — диаметр `.5` → грузовая, хотя метрическая форма.
- `16*6-8` / `18*7-8` — индустриальные (спецшина), а не «размер диска», хотя есть `*`.
- `Клюшка`/`волна`/`шашка` — маркер спецшины, даже если есть `PR`.

## 9. Признаки, которые НЕ определяют тип

Сезон (`летняя/зимняя/всесезонная`), шипы, `TL`/`TT`/`TTF`, `RunFlat`, `XL`, бренд, цвет,
`ET`/`DIA`/разболтовка для шин — это атрибуты. Тип товара они не задают (кроме дисков, где
разболтовка помогает отличить легковой диск от грузового, а не отдельный тип).

## 10. Чек-лист применения

1. Нормализовать строку (гомоглифы, `\xa0`, десятичные запятые).
2. Проверить нешинные слова: кольцо → камера → лента → диск.
3. Найти размер и определить его тип: метрический / дюймовый / сельхоз / индустриальный / мото.
4. Проверить маркеры спецтехники и TRA → `Спецшина`.
5. Проверить мото (категория поставщика, размер) → `Мотошина`.
6. По диаметру, PR, двойному индексу, оси и суффиксам выбрать `Грузовая` /
   `Легкогрузовая` / `Легковая`.
7. Тип определён **независимо**; категория поставщика — только сверка. При расхождении
   доверяем вычисленному типу, расхождение логируем.
8. Если категория поставщика пустая/некорректная — тип всё равно вычисляется по инструкции,
   позиция не пропускается.
9. При сомнении — отдавать приоритет названию над одиночным параметром и фиксировать кейс
   тестом рядом с причиной.
