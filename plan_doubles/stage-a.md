# Этап A — ключ группировки

← [План](../PLAN_DOUBLES.md) · дальше: [этап B](stage-b.md)

Основной эффект. Делать по порядку: A1 → A2 → A3. После каждого шага — тесты ключа/группировщика и прогон отчёта о дублях на том же наборе прайсов.

## A1. Не сравнивать поля, которые заполнены не у всех

**Зачем.** Мим пишет ось «Рулевая»/«Ведущая», остальные нет. Форточки ставят `TL` в title (~58% позиций), Мим и Запаска почти никогда. Для легковых эвристика «диаметр 22.5 → TL» не срабатывает — Форточки изолированы.

**Сделать**

- `axis` не класть в ключ, либо сравнивать только если значение есть у обеих строк.
- `intimacy` / `define_intimacy`: не считать слово `TL` в названии отдельным товаром. Учитывать камерность только при явном `TT`/`TTF` против `TL`.
- Решить, как это выразить при текущем `groupby` по точному кортежу: выкинуть поле из ключа (проще) или не подставлять `define_intimacy` из title для `TL`.

**Файлы:** `src/parsers/common_price_group_key.py`, `tests/test_parsers/test_common_price_group_key.py`, `tests/test_parsers/test_common_price_grouper.py`.

**Готово, когда**

- Одна и та же модель без `TL` в title и с `TL` (Форточки) попадает в одну группу.
- Мим с осью «Рулевая» склеивается с Запаской/Форточками без оси.
- Явный `TT` не склеивается с `TL`.
- Тесты `КАМА-NU 701` / `NU701` из grouper не ломаются из‑за оси/камерности.

## A2. Переписать `clear_model`

**Зачем.** Сейчас берётся кусок после первого дефиса без `.lower()`: `PW-1` и `PS-1` → `1`, `Кама-1260-1` и `Кама-1260-2` → `1260`, `SNOW CROSS 2` ≠ `Snow Cross 2`.

**Сделать**

- Нижний регистр, убрать пробелы.
- Срезать известный префикс бренда (`КАМА-`, имя manufacturer/brand), а не «всё после первого `-`».
- Модель хранить целиком: `pw-1` ≠ `ps-1`, `1260-1` ≠ `1260-2`.
- Сохранить совпадение `КАМА-NU 701` с `NU701`.

**Файлы:** `src/parsers/common_price_group_key.py`, `tests/test_parsers/test_common_price_group_key.py`.

**Готово, когда**

- `clear_model("КАМА-NU 701") == clear_model("NU701") == clear_model("NU 701")` (без учёта регистра).
- `PW-1` ≠ `PS-1`, `CW-2` ≠ `CA-2`, `Кама-1260-1` ≠ `Кама-1260-2`.
- `SNOW CROSS 2` == `Snow Cross 2`.
- Обновить parametrize `test_clear_model` (сейчас `"A-B-C" → "B"` — это старое поведение, его нужно заменить).

## A3. Не группировать пустую идентичность

**Зачем.** `None` становится `""`, все строки без размера и модели одного типа схлопываются: 21 GreenStone Автоснабжения, две разные камеры, Triangle 205/55R16 с 255/55R19.

**Сделать**

- Если нет размера (`width` и `diameter` пустые) **и** нет модели после `clear_model` — не вызывать `_mark_double_items`.
- `group_by_params` у таких строк может остаться уникальным (синглтон), в отчёт о дублях они не попадают.

**Файлы:** `src/parsers/common_price_grouper.py`, `tests/test_parsers/test_common_price_grouper.py`.

**Готово, когда**

- Две автокамеры без размера/модели не помечаются дублями.
- Две шины одного бренда без width/model не склеиваются.
- Пара с заполненным размером и моделью по-прежнему дублируется.
