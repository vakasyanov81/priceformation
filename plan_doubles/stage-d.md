## D1. Автоснабжение: размер, модель, бренд из title

**Зачем.** Парсер мапит только тип, title, сезон, шип, цену, остаток. Ключ пустой.

**Сделать**

- Вытащить из номенклатуры width / height / diameter / model / manufacturer (переиспользовать существующие хелперы title, если есть).
- Не подставлять вымышленные значения, если разбор не удался (A3 тогда не склеит мусор).

**Файлы:** `src/parsers/vendors/autosnab54_ru.py`, тесты вендора.

**Готово, когда**

- GreenStone разных размеров не в одной группе.
- Совпадающая с другим поставщиком модель Автоснабжения (если такая есть в прайсе) попадает в кросс-группу.

## D2. Форточки, диски: title из «Наименования», не только из колонок

**Зачем.** Title диска собирается заново из ширины / PCD / ET / цвета / модели плюс толщина, «усил.», б/к. Колонка «Наименование» почти выкидывается, «Заводской код» пустая. В отчёте о дублях три разных CAI выглядят одинаково:

```
9.0x22.5 10x335 ET175 281 Sil ZEPP 10/335/281/175 (16 мм) б/к
```

В прайсе это разные артикулы с одной ценой:

| CAI | Наименование |
|---|---|
| WHS522229 | `… Sil (YZ) (16 мм) (б/к)` |
| WHS525687 | `… Sil (HAP) alive (16 мм) (б/к) наруж. вентиль` |
| WHS531191 | `… Sil (HAP) (16 мм) (б/к) внутр. вентиль` |

Ключ группировки этих токенов не видит — группа остаётся. `(18 мм)` уже отрезается толщиной.

Другие хвосты в грузовых именах: `(JNTS)`, `под футорку`, `с вент.`, `(кольцо)`, нагрузка `4 500 кг`, применимость (прицеп / руль / Европеец). Числовые скобки вроде `(5221105)` — складской код, не геометрия.

**Сделать**

- Канон размера / бренда / модели оставить (как сейчас).
- Из исходного «Наименования» дописать в title то, чего нет в каноне: буквенный завод `(YZ)` / `(HAP)` / `(JNTS)`, `alive`, вентиль (`наруж.` / `внутр.`), `под футорку`, `с вент.`, `(кольцо)`. Толщина / усил. / б/к / «под камеру» уже есть — не дублировать.
- Целиком сырое имя в title не копировать (длинные «Китай, Камаз 6580 / Вольво…»).
- Те же различающие токены должны попадать в ключ группировки. Иначе title станет читаемым, а в `doubles_*.xlsx` склейка останется. Пустой хвост у Запаски/Мима vs заполненный у Форточек — ограничение как у C1 (wildcard позже, не в этом тикете).
- Числовой код в скобках `(5221105)` в ключ не класть.

**Файлы:** `src/parsers/vendors/four_tochki/four_tochki_disk_title.py`, `four_tochki_sheet2.py`, ключ (`common_price_group_key.py` / `common_price_group_fields.py`), тесты вендора и ключа.

**Готово, когда**

- Три ZEPP `9x22.5 10x335 ET175 (16 мм) б/к` — разные title и не одна группа.
- `(YZ)` и `(HAP)` одной геометрии и толщины не дубли.
- `наруж. вентиль` и `внутр. вентиль` не дубли.
- Легковой диск без хвоста в «Наименовании» (Alcasta / iFree) — title как сейчас.
- Регрессии sheet2: `6.5x16 5x114.3 ET45 … Alcasta M35`, `14.0` → `14`.
